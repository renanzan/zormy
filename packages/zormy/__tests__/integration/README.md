# Testes de integração

Este diretório está reservado para testes mais **end-to-end** que envolvam vários módulos do Zormy (Form + Wizard + resolvers + campos aninhados, etc.).

Por enquanto não há testes aqui. Quando houver fluxos que exijam validar o comportamento integrado de múltiplas partes da lib, adicione-os neste diretório.
