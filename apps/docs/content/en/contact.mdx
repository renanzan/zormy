# Contact

Found a bug, have a suggestion or want to contribute to Zormy? Use the channels below.

## Report Issues

- **Bugs and errors**: Open a [GitHub Issue](https://github.com) with a description, steps to reproduce and the package version.
- **Usage questions**: Check the [documentation](/docs), [examples](/examples) and [tips](/docs/tips). If you still have questions, use Issues with the discussion label.

## Contribute

Contributions are welcome. Check the project repository on GitHub for:

- **Zormy** package source code
- Contribution guide and code standards
- Roadmap and planned improvements
