# Contato

Encontrou um bug, tem uma sugestão ou quer contribuir com o Zormy? Use os canais abaixo.

## Reportar problemas

- **Bugs e erros**: abra uma [Issue no GitHub](https://github.com/renanzan/zormy/issues) com descrição, passos para reproduzir e versão do pacote.
- **Dúvidas de uso**: consulte a [documentação](/docs), os [exemplos](/examples) e as [dicas](/docs/tips). Se ainda restar dúvida, use as Issues com o label de discussão.

## Contribuir

Contribuições são bem-vindas. Veja o repositório do projeto no GitHub para:

- Código-fonte do pacote **Zormy**
- Guia de contribuição e padrões de código
- Roadmap e melhorias planejadas
