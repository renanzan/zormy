# Getting Started

<Callout type="info" emoji="🚀">
	Zormy is a library for building typed and reusable forms with TypeScript, Zod, and React Hook
	Form. It proposes an approach inspired by atomic design for forms (atoms → molecules → organisms →
	templates). See [Form Design](/docs/form-design) for the concept and
	[Tips](/docs/tips#recommended-project-structure) for project structure. Get started in minutes!
</Callout>

If you haven’t installed it yet, see [Installation](/docs/installation).

## First form

1. **Define a field** with `field("key").schema(zodSchema).render(...)`.
2. **Create the form** with `useForm` and `zormyResolver({ fields: [...] })`.
3. **Render** inside `<Form methods={form}>`.

<CodeExample editorHeight={380} code={firstFormCode} />

The **validation mode** (`mode`) defines when fields are validated: `"onChange"`, `"onBlur"`, `"onSubmit"`, `"onTouched"` or `"all"`. See [Forms](/docs/forms) for details.
