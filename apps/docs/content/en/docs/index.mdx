# Zormy Documentation

**Zormy** is a library for building **typed, reusable** forms in React with TypeScript, Zod and React Hook Form.

## Main features

- **Strong typing** — type inference from Zod schemas and fields
- **Declarative validation** — static or dynamic schemas per field ([Zod Integration](/en/docs/zod-integration))
- **Reusable fields** — define once, use in multiple forms and wizards
- **Wizards** — multi-step flows with per-step validation and navigation
