# Zormy Documentation

**Zormy** is a library for building **typed and reusable** forms in React, combining TypeScript, Zod, and React Hook Form. It proposes a way to handle forms inspired by **atomic design**: building screens from **atoms** (fields), **molecules** (groups of fields), **organisms** (forms), and **templates** (wizards). See [Form Design](/docs/form-design) for this approach and [Tips](/docs/tips) for project structure.

## Key Features

- **Strong typing** — type inference from Zod schemas and fields
- **Declarative validation** — static or dynamic schemas per field ([Zod Integration](/docs/zod-integration))
- **Reusable fields** — build once, use across multiple forms and wizards
- **Wizards** — multi-step flows with per-step validation and navigation
