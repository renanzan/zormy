# Wizards

Wizards organize forms into **multiple steps**, with per-step validation and navigation (next/back). Zormy provides strong typing for steps and fields.

## Concepts

1. **Steps** — array of names (e.g., `["personal", "contact"] as const`).
2. **Fields per step** — mapping `{ personal: [NameField], contact: [EmailField] }`.
3. **Configuration** — `createWizardConfig({ steps, fields })` (and optionally `shouldIncludeStep`).
4. **Components** — `createWizardComponents(config)` returns `{ Wizard, Step }`.
5. **Hook** — `useWizard({ ...config, defaultValues, onSubmit, ... })`.
6. **Render** — `<Wizard methods={wizard}>` and `<Step step="personal">` with fields and navigation buttons.

## Navigation

The object returned by `useWizard` includes:

| Property / Method            | Description                                                                 |
| ---------------------------- | --------------------------------------------------------------------------- |
| `currentStep`                | Current step                                                                |
| `currentStepIndex`           | Step index (0-based)                                                        |
| `steps`                      | List of steps (filtered if using `shouldIncludeStep`)                       |
| `totalSteps`                 | Number of steps                                                             |
| `isFirstStep` / `isLastStep` | Booleans for UI                                                             |
| `next()`                     | Advances to the next step (validates current step; returns `Promise<void>`) |
| `back()`                     | Goes back to the previous step                                              |
| `goToStep(step)`             | Goes to a specific step                                                     |

When using the wizard, it is **not** necessary to pass `onSubmit` to `<Wizard>`: the "Finish" (submit) button internally triggers `wizard.next()`, which validates the last step and calls the `onSubmit` passed to `useWizard` with **all accumulated wizard data**.

## Callbacks: per-step data and final submission

The wizard accumulates values from each step as you move forward. Use the callbacks in `useWizard`:

| Callback                                         | When it is called                                           | What it receives                                                                                                                     |
| ------------------------------------------------ | ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **`onStepSubmit(stepData, step, allDataSoFar)`** | When clicking "Next" (or "Finish" on the last step)         | `stepData`: validated data of the current step; `step`: step name; `allDataSoFar`: all data filled so far (previous steps + current) |
| **`onSubmit(data)`**                             | Only when finishing the wizard (last step, "Finish" button) | `data`: **all** wizard data (all completed steps)                                                                                    |

Example: log current step data when advancing and all data when finishing:

```tsx
const wizard = useWizard({
	...wizardConfig,
	defaultValues: { name: "", email: "" },
	onStepSubmit: (stepData, step, allDataSoFar) => {
		console.log("Completed step:", step, "step data:", stepData, "all data so far:", allDataSoFar);
	},
	onSubmit: (data) => console.log("Wizard finished with all data:", data),
});
```

## Conditional steps

For steps that appear or disappear based on form values, use `shouldIncludeStep` in `createWizardConfig`:

```tsx
const wizardConfig = createWizardConfig({
	steps: ["personal", "address", "payment"] as const,
	fields: {
		personal: [NameField],
		address: [StreetField, CityField],
		payment: [CardField],
	},
	shouldIncludeStep: (step, formValues) => {
		if (step === "address") return formValues.needsShipping === true;
		if (step === "payment") return true;
		return true;
	},
});
```

The wizard only shows and validates steps for which `shouldIncludeStep` returns `true`. `steps`, `totalSteps`, and navigation will consider only those steps.

## Auto-save

You can automatically save when changing steps using the `autoSave` option in `useWizard`:

```tsx
const wizard = useWizard({
	...wizardConfig,
	defaultValues: { name: "", email: "" },
	autoSave: async ({ step, validChangedData }) => {
		await api.saveStep(step, validChangedData);
	},
	onSubmit: (data) => console.log(data),
});
```

Inside wizard children, use `useAutoSaveContext()` to display status (saving, saved, error) and `lastSaved`:

```tsx
function AutoSaveStatus() {
	const autoSave = useAutoSaveContext();
	return (
		<div>
			{autoSave.status === "saving" && "Saving..."}
			{autoSave.status === "saved" && "Saved"}
			{autoSave.status === "error" && "Error saving"}
		</div>
	);
}
```

## Wizard context

To access the wizard in child components (for example, navigation buttons in a layout), use `useWizardContext`:

```tsx
const wizard = useWizardContext<typeof wizardConfig>();
wizard.next();
wizard.back();
wizard.goToStep("contact");
```

## Other `useWizard` options

| Option                                       | Description                                                                       |
| -------------------------------------------- | --------------------------------------------------------------------------------- |
| `defaultValues`                              | Initial values (object, sync or async function); must cover all keys of all steps |
| `onSubmit`                                   | Callback when the wizard is finished (last step); receives all filled data        |
| `onStepSubmit(stepData, step, allDataSoFar)` | Callback when advancing steps; receives stepData, step, and allDataSoFar          |
| `initialStep`                                | Initial step                                                                      |
| `mode`                                       | react-hook-form validation mode (`"onChange"`, `"onBlur"`, etc.)                  |
| `controlledStep`                             | Externally controlled step (e.g., via URL query)                                  |
| `onStepChange`                               | Callback when the step changes                                                    |

For the complete API (including `WizardProvider`, types, and auto-save), see [API Reference](/docs/api-reference).
