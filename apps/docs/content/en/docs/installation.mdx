# Installation

<Steps>
  ### Install Zormy and the dependencies

With pnpm:

```bash
pnpm add zormy zod react-hook-form @hookform/resolvers
```

With npm:

```bash
npm install zormy zod react-hook-form @hookform/resolvers
```

With yarn:

```bash
yarn add zormy zod react-hook-form @hookform/resolvers
```

</Steps>

## Dependencies

Zormy uses the following **peer dependencies** (already included in the commands above):

| Package               | Version  | Usage                                  |
| --------------------- | -------- | -------------------------------------- |
| `react`               | ^18      | React runtime                          |
| `react-hook-form`     | ^7.71.1  | Form control                           |
| `zod`                 | ^3.25.28 | Validation and schemas                 |
| `@hookform/resolvers` | ^5.2.2   | Bridge between Zod and react-hook-form |

<Callout type="info">
	In new projects, also install `zod` and `react-hook-form` if they are not yet in your project.
	Zormy’s `zormyResolver` builds the schema from the fields and uses the react-hook-form ecosystem.
</Callout>

## Next step

After installing, follow [Getting Started](/docs/get-started) to create your first form in just a few minutes.
