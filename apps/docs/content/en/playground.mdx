# Playground

Try creating complex wizards and see how a Schema transforms into a multi-step Wizard in real time.

<Playground />

## How to Use

1. **Define the Steps**: List the wizard steps in the `steps` array.
2. **Define the Fields**: For each step, define the fields with:
   - `key`: Unique field key
   - `schema`: **Real Zod code** — evaluated at runtime. Use any Zod API: `z.string()`, `z.coerce.number()`, `.transform()`, `.preprocess()`, `.refine()`, etc.
   - `defaultValue` (optional): Field default value

3. **Live Preview**: The preview updates automatically as you edit (debounced). No "Apply" button needed. Use "Restaurar padrão" to reset.

## Basic Example

```json
{
	"steps": ["personal", "contact"],
	"fields": {
		"personal": [
			{ "key": "name", "schema": "z.string().min(3)" },
			{ "key": "age", "schema": "z.number().min(18)" }
		],
		"contact": [
			{ "key": "email", "schema": "z.string().email()" },
			{ "key": "phone", "schema": "z.string().optional()" }
		]
	}
}
```

## Advanced Example

```json
{
	"steps": ["account", "profile", "preferences"],
	"fields": {
		"account": [
			{ "key": "username", "schema": "z.string().min(3).max(20)" },
			{ "key": "email", "schema": "z.string().email()" },
			{ "key": "password", "schema": "z.string().min(8)" }
		],
		"profile": [
			{ "key": "firstName", "schema": "z.string().min(1)" },
			{ "key": "lastName", "schema": "z.string().min(1)" },
			{ "key": "bio", "schema": "z.string().max(500).optional()" }
		],
		"preferences": [
			{ "key": "newsletter", "schema": "z.boolean()", "defaultValue": false },
			{ "key": "theme", "schema": "z.enum(['light', 'dark', 'auto'])" }
		]
	}
}
```

## Available Schemas

### Basic Types

- `z.string()` - String
- `z.number()` - Number
- `z.boolean()` - Boolean
- `z.date()` - Date

### String Validations

- `z.string().min(n)` - Minimum length
- `z.string().max(n)` - Maximum length
- `z.string().email()` - Email format
- `z.string().url()` - URL format
- `z.string().regex(/pattern/)` - Regex pattern

### Number Validations

- `z.number().min(n)` - Minimum value
- `z.number().max(n)` - Maximum value
- `z.number().int()` - Integers only
- `z.number().positive()` - Positive numbers only

### Modifiers

- `.optional()` - Optional field
- `.nullable()` - Allows null
- `.default(value)` - Default value

### Others

- `z.enum(['val1', 'val2'])` - Enum
- `z.array(z.string())` - Array of strings

## Tips

- **Number fields**: Use `z.number()` — the playground renders a number input and sends values as numbers.
- **Booleans**: Use `z.boolean()` — a checkbox is rendered.
- **Enums**: Use `z.enum(['a','b'])` — a select is rendered.
- Use `.transform()`, `.preprocess()`, `.refine()` and any Zod API in `schema`; the code is evaluated in a sandbox with `z` in scope.
- After submitting, expand "Dados enviados (onComplete)" to see the parsed payload.
