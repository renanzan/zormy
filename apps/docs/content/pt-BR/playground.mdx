# Playground

Experimente criar wizards complexos e veja como um Schema se transforma em um Wizard multi-step em tempo real.

<Playground />

## Como Usar

1. **Defina os Steps**: Liste os steps do wizard no array `steps`
2. **Defina os Campos**: Para cada step, defina os campos com:
   - `key`: Chave única do campo
   - `schema`: **Código Zod real** — avaliado em tempo de execução. Use qualquer API do Zod: `z.string()`, `z.coerce.number()`, `.transform()`, `.preprocess()`, `.refine()`, etc.
   - `defaultValue` (opcional): Valor padrão do campo

3. **Preview ao vivo**: O preview atualiza automaticamente ao editar (com debounce). Não é preciso clicar em "Aplicar". Use "Restaurar padrão" para resetar.

## Exemplo Básico

```json
{
	"steps": ["personal", "contact"],
	"fields": {
		"personal": [
			{ "key": "name", "schema": "z.string().min(3)" },
			{ "key": "age", "schema": "z.number().min(18)" }
		],
		"contact": [
			{ "key": "email", "schema": "z.string().email()" },
			{ "key": "phone", "schema": "z.string().optional()" }
		]
	}
}
```

## Exemplo Avançado

```json
{
	"steps": ["account", "profile", "preferences"],
	"fields": {
		"account": [
			{ "key": "username", "schema": "z.string().min(3).max(20)" },
			{ "key": "email", "schema": "z.string().email()" },
			{ "key": "password", "schema": "z.string().min(8)" }
		],
		"profile": [
			{ "key": "firstName", "schema": "z.string().min(1)" },
			{ "key": "lastName", "schema": "z.string().min(1)" },
			{ "key": "bio", "schema": "z.string().max(500).optional()" }
		],
		"preferences": [
			{ "key": "newsletter", "schema": "z.boolean()", "defaultValue": false },
			{ "key": "theme", "schema": "z.enum(['light', 'dark', 'auto'])" }
		]
	}
}
```

## Schemas Disponíveis

### Tipos Básicos

- `z.string()` - String
- `z.number()` - Número
- `z.boolean()` - Boolean
- `z.date()` - Data

### Validações de String

- `z.string().min(n)` - Mínimo de caracteres
- `z.string().max(n)` - Máximo de caracteres
- `z.string().email()` - Formato de email
- `z.string().url()` - Formato de URL
- `z.string().regex(/pattern/)` - Padrão regex

### Validações de Número

- `z.number().min(n)` - Valor mínimo
- `z.number().max(n)` - Valor máximo
- `z.number().int()` - Apenas inteiros
- `z.number().positive()` - Apenas positivos

### Modificadores

- `.optional()` - Campo opcional
- `.nullable()` - Permite null
- `.default(value)` - Valor padrão

### Outros

- `z.enum(['val1', 'val2'])` - Enum
- `z.array(z.string())` - Array de strings

## Dicas

- **Campos numéricos**: Use `z.number()` — o playground renderiza input numérico e envia valores como número.
- **Booleanos**: Use `z.boolean()` — é renderizado um checkbox.
- **Enums**: Use `z.enum(['a','b'])` — é renderizado um select.
- Use `.transform()`, `.preprocess()`, `.refine()` e qualquer API do Zod em `schema`; o código é avaliado em um sandbox com `z` no escopo.
- Após enviar, expanda "Dados enviados (onComplete)" para ver o payload parseado.
