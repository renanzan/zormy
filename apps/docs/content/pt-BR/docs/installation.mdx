# Instalação

<Steps>
  ### Instale o Zormy e as dependências

Com pnpm:

```bash
pnpm add zormy zod react-hook-form @hookform/resolvers
```

Com npm:

```bash
npm install zormy zod react-hook-form @hookform/resolvers
```

Com yarn:

```bash
yarn add zormy zod react-hook-form @hookform/resolvers
```

</Steps>

## Dependências

O Zormy usa as seguintes **peer dependencies** (já incluídas nos comandos acima):

| Pacote                | Versão   | Uso                               |
| --------------------- | -------- | --------------------------------- |
| `react`               | ^18      | Runtime React                     |
| `react-hook-form`     | ^7.71.1  | Controle de formulário            |
| `zod`                 | ^3.25.28 | Validação e schemas               |
| `@hookform/resolvers` | ^5.2.2   | Ponte entre Zod e react-hook-form |

<Callout type="info">
	Em projetos novos, instale também `zod` e `react-hook-form` se ainda não estiverem no projeto. O
	`zormyResolver` do Zormy monta o schema a partir dos campos e usa o ecossistema do
	react-hook-form.
</Callout>
