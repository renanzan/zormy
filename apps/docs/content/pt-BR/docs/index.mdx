# Documentação do Zormy

O **Zormy** é uma biblioteca para criar formulários **tipados e reutilizáveis** em React, combinando TypeScript, Zod e React Hook Form.

## Recursos principais

- **Tipagem forte** — inferência de tipos a partir dos schemas Zod e dos campos
- **Validação declarativa** — schemas estáticos ou dinâmicos por campo ([Integração Zod](/docs/zod-integration))
- **Campos reutilizáveis** — crie uma vez, use em vários formulários e wizards
- **Wizards** — fluxos multi-step com validação por etapa e navegação
