# Wizards

Wizards organizam formulários em **múltiplos passos** (steps), com validação por etapa e navegação (próximo/voltar). O Zormy oferece tipagem forte para steps e campos.

## Conceitos

1. **Steps** — array de nomes (ex: `["personal", "contact"] as const`).
2. **Fields por step** — mapeamento `{ personal: [NameField], contact: [EmailField] }`.
3. **Configuração** — `createWizardConfig({ steps, fields })` (e opcionalmente `shouldIncludeStep`).
4. **Componentes** — `createWizardComponents(config)` retorna `{ Wizard, Step }`.
5. **Hook** — `useWizard({ ...config, defaultValues, onSubmit, ... })`.
6. **Render** — `<Wizard methods={wizard}>` e `<Step step="personal">` com os campos e botões de navegação.

## Navegação

O objeto retornado por `useWizard` inclui:

| Propriedade / Método         | Descrição                                                                 |
| ---------------------------- | ------------------------------------------------------------------------- |
| `currentStep`                | Step atual                                                                |
| `currentStepIndex`           | Índice do step (0-based)                                                  |
| `steps`                      | Lista de steps (filtrados se usar `shouldIncludeStep`)                    |
| `totalSteps`                 | Número de steps                                                           |
| `isFirstStep` / `isLastStep` | Booleanos para UI                                                         |
| `next()`                     | Avança para o próximo step (valida o step atual; retorna `Promise<void>`) |
| `back()`                     | Volta para o step anterior                                                |
| `goToStep(step)`             | Vai para um step específico                                               |

Ao usar o wizard, **não** é necessário passar `onSubmit` no `<Wizard>`: o botão "Finalizar" (submit) dispara internamente `wizard.next()`, que valida o último step e chama o `onSubmit` passado em `useWizard` com **todos os dados acumulados** do wizard.

## Callbacks: dados por step e ao finalizar

O wizard acumula os valores de cada step conforme você avança. Use os callbacks em `useWizard`:

| Callback                                         | Quando é chamado                                               | O que recebe                                                                                                                                         |
| ------------------------------------------------ | -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`onStepSubmit(stepData, step, allDataSoFar)`** | Ao clicar em "Próximo" (ou "Finalizar" no último step)         | `stepData`: dados validados do step atual; `step`: nome do step; `allDataSoFar`: todos os dados preenchidos até o momento (steps anteriores + atual) |
| **`onSubmit(data)`**                             | Somente ao finalizar o wizard (último step, botão "Finalizar") | `data`: **todos** os dados do wizard (todos os steps preenchidos)                                                                                    |

Exemplo: exibir dados do step atual ao avançar e todos os dados ao finalizar:

```tsx
const wizard = useWizard({
	...wizardConfig,
	defaultValues: { name: "", email: "" },
	onStepSubmit: (stepData, step, allDataSoFar) => {
		console.log(
			"Step concluído:",
			step,
			"dados do step:",
			stepData,
			"tudo até agora:",
			allDataSoFar
		);
	},
	onSubmit: (data) => console.log("Wizard finalizado com todos os dados:", data),
});
```

## Steps condicionais

Para steps que aparecem ou desaparecem conforme os valores do formulário, use `shouldIncludeStep` em `createWizardConfig`:

```tsx
const wizardConfig = createWizardConfig({
	steps: ["personal", "address", "payment"] as const,
	fields: {
		personal: [NameField],
		address: [StreetField, CityField],
		payment: [CardField],
	},
	shouldIncludeStep: (step, formValues) => {
		if (step === "address") return formValues.needsShipping === true;
		if (step === "payment") return true;
		return true;
	},
});
```

O wizard só mostra e valida os steps para os quais `shouldIncludeStep` retorna `true`. `steps`, `totalSteps` e a navegação passam a considerar apenas esses steps.

## Auto-save

Você pode salvar automaticamente ao mudar de step com a opção `autoSave` do `useWizard`:

```tsx
const wizard = useWizard({
	...wizardConfig,
	defaultValues: { name: "", email: "" },
	autoSave: async ({ step, validChangedData }) => {
		await api.saveStep(step, validChangedData);
	},
	onSubmit: (data) => console.log(data),
});
```

Dentro dos filhos do wizard, use `useAutoSaveContext()` para exibir status (salvando, salvo, erro) e `lastSaved`:

```tsx
function AutoSaveStatus() {
	const autoSave = useAutoSaveContext();
	return (
		<div>
			{autoSave.status === "saving" && "Salvando..."}
			{autoSave.status === "saved" && "Salvo"}
			{autoSave.status === "error" && "Erro ao salvar"}
		</div>
	);
}
```

## Contexto do wizard

Para acessar o wizard em componentes filhos (por exemplo, botões de navegação em um layout), use `useWizardContext`:

```tsx
const wizard = useWizardContext<typeof wizardConfig>();
wizard.next();
wizard.back();
wizard.goToStep("contact");
```

## Outras opções do `useWizard`

| Opção                                        | Descrição                                                                                               |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `defaultValues`                              | Valores iniciais (objeto, função síncrona ou assíncrona); deve cobrir todas as chaves de todos os steps |
| `onSubmit`                                   | Callback quando o wizard é finalizado (último step); recebe todos os dados preenchidos                  |
| `onStepSubmit(stepData, step, allDataSoFar)` | Callback ao avançar de step; “avançado” recebe stepData, step e allDataSoFar                            |
| `initialStep`                                | Step inicial                                                                                            |
| `mode`                                       | Modo de validação do react-hook-form (`"onChange"`, `"onBlur"`, etc.)                                   |
| `controlledStep`                             | Step controlado externamente (ex.: por query da URL)                                                    |
| `onStepChange`                               | Callback quando o step muda                                                                             |

Para a API completa (incluindo `WizardProvider`, tipos e auto-save), veja [Referência API](/docs/api-reference).
