# Começando

<Callout type="info" emoji="🚀">
	Zormy é uma biblioteca para criar formulários tipados e reutilizáveis com TypeScript, Zod e React
	Hook Form. Ele propõe uma abordagem inspirada no atomic design para formulários (átomos → moléculas → organismos → templates). Veja [Design de formulários](/docs/form-design) para o conceito e [Dicas](/docs/tips#estrutura-de-projeto-recomendada) para estrutura de projeto. Comece em minutos!
</Callout>

Se ainda não instalou, veja [Instalação](/docs/installation).

## Primeiro formulário

1. **Defina um campo** com `field("chave").schema(zodSchema).render(...)`.
2. **Crie o formulário** com `useForm` e `zormyResolver({ fields: [...] })`.
3. **Renderize** dentro de `<Form methods={form}>`.

<CodeExample editorHeight={380} code={firstFormCode} />

O **modo de validação** (`mode`) define quando os campos são validados: `"onChange"`, `"onBlur"`, `"onSubmit"`, `"onTouched"` ou `"all"`. Veja [Forms](/docs/forms) para detalhes.
