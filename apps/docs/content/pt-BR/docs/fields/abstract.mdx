# Campos abstratos

**Campos abstratos** são templates de campo sem chave fixa. Você define schema e render uma vez e cria campos concretos com `.extend({ key: "..." })`. Isso reduz duplicação quando vários campos compartilham o mesmo tipo e UI.

## Uso básico

```tsx
import { z } from "zod";
import { abstractField, Form, useZormy } from "zormy";

const BaseTextField = abstractField()
	.schema(z.string().min(3, "Mín. 3 caracteres"))
	.render(({ register, fieldState }) => (
		<div>
			<input {...register()} />
			{fieldState.error && <span>{fieldState.error.message}</span>}
		</div>
	));

const NameField = BaseTextField.extend({ key: "name" });
const EmailField = BaseTextField.extend({ key: "email" });
```

## Exemplo: campo de moeda

Campo de valor reutilizável que formata e faz parse de número:

```tsx
const CurrencyFieldBase = abstractField()
	.schema(z.number().min(0, "Deve ser positivo"))
	.render(({ register, fieldState }, props) => (
		<div>
			<label>{props?.label ?? "Valor"}</label>
			<input
				type="number"
				step="0.01"
				{...register({ valueAsNumber: true })}
			/>
			{fieldState.error && <span>{fieldState.error.message}</span>}
		</div>
	));

const PriceField = CurrencyFieldBase.extend({ key: "price" });
const DiscountField = CurrencyFieldBase.extend({ key: "discount" });
```

Você pode sobrescrever schema ou render em `.extend()` para variantes (ex.: min/max diferentes).

## Exemplo: campo de data

```tsx
const DateFieldBase = abstractField()
	.schema(z.string().min(1, "Obrigatório"))
	.render(({ register, fieldState }, props) => (
		<div>
			<label>{props?.label ?? "Data"}</label>
			<input type="date" {...register()} />
			{fieldState.error && <span>{fieldState.error.message}</span>}
		</div>
	));

const BirthDateField = DateFieldBase.extend({ key: "birthDate" });
const DueDateField = DateFieldBase.extend({ key: "dueDate" });
```

## Exemplo: campo de arquivo

```tsx
const FileFieldBase = abstractField()
	.schema(
		z
			.instanceof(FileList)
			.refine((files) => files?.length > 0, "Selecione um arquivo")
	)
	.render(({ register, fieldState }) => (
		<div>
			<input type="file" {...register()} />
			{fieldState.error && <span>{fieldState.error.message}</span>}
		</div>
	));

const AvatarField = FileFieldBase.extend({ key: "avatar" });
const DocumentField = FileFieldBase.extend({ key: "document" });
```

## Sobrescrevendo em `.extend()`

Você pode sobrescrever `key`, `schema`, `render`, `dependsOn` ou `props` (props padrão do componente):

```tsx
const RequiredEmailField = BaseTextField.extend({
	key: "email",
	schema: z.string().email("Email inválido").min(1, "Obrigatório"),
});
```

Veja [Props customizadas](/docs/fields/custom-props) para usar `props` no render e `.extend({ props: { ... } })`.
